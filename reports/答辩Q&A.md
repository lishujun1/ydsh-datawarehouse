# 答辩 Q&A 预判与标准回答

> 按"评委可能问什么 → 我们怎么答 → 证据在哪"组织。答辩时主动亮出第12条（已知问题），比被问出来强。

## 1. 为什么品类销售额 5.08 亿、GMV 3611 万、当日 GMV 5 万，三个数量级？

**答**：口径不同，不是 bug。
- 品类销售额是**明细行口径**（`quantity × unit_price × (1-discount)`），未摊分订单级优惠；
- GMV 是**订单实付口径**（`sum(pay_amount)`）；
- 当日 GMV 是**单日切片**，渠道/品类表是全年累计。

三者在 `docs/指标定义.md` 第二节"口径差异说明"中已声明，**不可加总或直接比较**。

## 2. 复购率为什么是 100%？

**答**：合理，但需分三层看。
- **数据层**：模拟数据 1000 名下单用户人均 14.4 单，全部满足"下单≥2次"，故复购率=100%，这是数据构造特征；
- **工程层**：早期 ADS 层用 `sum(case when cnt>=2 then 1 else 0 end)` 在 join 后被放大，误算 14.398%；后用 `count(distinct case when cnt>=2 then user_id end)` 修正，与手工核对 SQL 一致得 100%。NL2SQL 一直返回 1.0，反而是对的。修正过程记录在 `reports/AI智能洞察报告.md` 第 4 节；
- **业务层**：真实新零售复购率通常 20%~40%，100% 不可直接用于业务决策，报告中已注明。

## 3. 线性回归 MAPE 9.26% 能用于经营决策吗？

**答**：不能。`reports/预测建模分析报告.md` 第 5 节已写 5 条边界：对突变不敏感、样本仅 366 天、误差绝对值 8000~10000 元、特征单一、MAPE 超 15% 不做强承诺。模型仅作趋势参考，不适用于精确预算。

## 4. 大屏数据是真的吗？

**答**：`api_server.py` 当前为前端联调 mock，真实链路见 `src/ai_insight.py` 的 PyHive 查询（查 `ads_sales_daily` / `ads_category_top10`）。生产环境应改为直连 ADS 表，改造方案已在 `docs/部署手册.md` 第六节说明。

## 5. 四层数仓为什么只有一个库 `ydsh_ods`？

**答**：教学环境用单库 + 表名前缀模拟分层，生产环境应为 `ods` / `dwd` / `dws` / `ads` 四个 database。`docs/数仓架构设计文档` 第三节已注明。

## 6. DWD 事实表 15000 行，ODS 15600 行，少的 600 哪去了？

**答**：去重。`sql/clean/clean_duplicate.sql` 用 `row_number() over(partition by order_id order by order_time desc)` 保留一条，去重前后差与预评估阶段发现的 586 个重复 `order_id` 一致（部分重复 3~4 次，故行数差略大于 586）。

## 7. 金额置 NULL 602 条占 4%，会不会影响 GMV？

**答**：会低估，报告已注明。选择置 NULL 而非删除，是为保留行数和其他字段；`sum(pay_amount)` 自动忽略 NULL。有效订单客单价 2508.45，含 NULL 客单价 2407.78，两个口径都在报告中列出。

## 8. order_status 1/2/3/4 映射依据？

**答**：按数据字典示例推断（1=待支付、2=已支付、3=退款中、4=已取消），尚未与业务方正式确认，已在 `reports/数据质量对比报告` 遗留问题 2 中标注。

## 9. NL2SQL 怎么防注入/防编造？

**答**：三重校验——`assert sql.lower().startswith("select")` 拒绝非查询语句；Prompt 注入枚举值和字段约束；`fix_sql()` 兜底修正 Hive 不兼容写法。`reports/AI应用反思.md` 第 1、2 条有记录。
