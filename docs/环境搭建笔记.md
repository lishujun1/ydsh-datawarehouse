## 问题1：Docker 启动 Hive 报错 ClassNotFoundException
- 现象：hive-metastore 容器启动后立即退出，日志显示找不到 com.mysql.cj.jdbc.Driver。
- 原因：官方镜像不包含 MySQL JDBC 驱动。
- 解决：下载驱动 jar 包，编写 Dockerfile COPY 到 /opt/hive/lib/，构建自定义镜像 my-hive:4.0.0。

## 问题2：3306 端口冲突
- 现象：MySQL 容器启动失败。
- 解决：将 docker-compose.yml 中的 MySQL 端口改为 "3307:3306"。

## 问题3：Git 提交失败
- 现象：在执行完 SQL 后，git status 显示 clean。
- 解决：在本地创建 sql/ods 和 sql/clean 目录，保存 .sql 文件后再提交。
