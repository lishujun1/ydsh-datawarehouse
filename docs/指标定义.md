# 指标定义文档（第3周）

| 指标 | 口径 | 计算式 |
|---|---|---|
| GMV | 所有有效订单实付金额之和 | sum(pay_amount)，排除 NULL |
| 订单量 | 去重订单数 | count(distinct order_id) |
| 客单价 AOV | GMV ÷ 订单量 | sum(pay_amount)/count(distinct order_id) |
| 活跃用户数 | 有下单行为的去重用户数 | count(distinct user_id) |
| 复购率 | 下单≥2次用户数 ÷ 下单用户数 | 子查询统计 |
| 品类销售占比 | 品类销售额 ÷ 总GMV | 窗口或子查询 |
