# 云购生活项目 · 全链路启动与验证手册

## 第 0 步：前提

- Docker Desktop 已打开（任务栏鲸鱼图标稳定，不转圈）
- 项目根目录：`D:\ydsh-datawarehouse`
- `.env` 已配置好：`MYSQL_ROOT_PASSWORD=root`、`SUPERSET_SECRET_KEY=ydsh_superset_secret_key_2024_please_change_me`、`DEEPSEEK_API_KEY=sk-xxx`
- `mysql-connector-java-8.0.28.jar` 在根目录
- `模拟数据/` 下有 6 个 CSV

---

## 第 1 步：启动容器（4 个服务）

```powershell
cd D:\ydsh-datawarehouse
docker compose up -d
```

**等待 1~2 分钟**，然后确认状态：

```powershell
docker ps
```

**预期看到 4 个容器，状态均为 `Up`**：
- `mysql`（端口 3307）
- `hive-metastore`（端口 9083）
- `hive-server`（端口 10000 / 10002）
- `superset`（端口 8088，可能显示 `(healthy)`）

**如果某个容器 `Exited`**：
```powershell
docker logs <容器名> --tail 30
```
看报错，常见是 mysql 没起好、JDBC 驱动没挂载。

---

## 第 2 步：验证数仓数据（Hive）

### 2.1 验证核心 KPI

```powershell
docker exec -it hive-server beeline -u jdbc:hive2://localhost:10000 -e "select * from ydsh_ods.ads_core_kpi;"
```

**预期输出**：
```
| gmv          | order_cnt | aov     | active_users | repurchase_rate |
| 3.611668706E7| 14398     | 2508.45 | 1000         | 1.0             |
```

> `3.611668706E7` = 36,116,687.06，科学计数法显示，正常。

### 2.2 验证四层行数

```powershell
docker exec -it hive-server beeline -u jdbc:hive2://localhost:10000 -e "select 'ods_order' t, count(*) c from ydsh_ods.ods_order union all select 'dwd_order', count(*) from ydsh_ods.dwd_order union all select 'dwd_order_item', count(*) from ydsh_ods.dwd_order_item union all select 'ads_sales_daily', count(*) from ydsh_ods.ads_sales_daily;"
```

**预期输出**：
```
| ods_order        | 15600  |
| dwd_order        | 15000  |
| dwd_order_item   | 37549  |
| ads_sales_daily  | 366    |
```

**4 个数字全对上 = 数据链路健康。**

### 2.3 验证数据质量数字（可选，答辩备用）

```powershell
docker exec -it hive-server beeline -u jdbc:hive2://localhost:10000 -e "select count(*) from ydsh_ods.ods_order where pay_amount < 0;"
```
预期：**310**（负金额）

```powershell
docker exec -it hive-server beeline -u jdbc:hive2://localhost:10000 -e "select count(*) from ydsh_ods.ods_user where email is null or email='';"
```
预期：**193**（邮箱缺失）

## 第 3 步：验证 Superset

### 3.1 确认容器状态

```powershell
docker ps | findstr superset
```

预期：`Up ... (healthy)`。

### 3.2 浏览器验证

打开 **http://localhost:8088**

- 账号：`admin`
- 密码：`admin123`

**验证标准**：
- 能登录；
- 左侧 `Dashboards` 能看到仪表板；
- 打开仪表板，图表正常显示；
- 筛选器（日期/品类）能联动。

### 3.3 如果 Superset 报错（历史坑，已修，备用）

若出现 `ValueError: Invalid decryption key`，执行：

```powershell
docker exec -it mysql mysql -uroot -proot -e "USE superset; UPDATE dbs SET encrypted_extra = NULL;"
docker exec -it mysql mysql -uroot -proot -e "USE superset; DELETE FROM key_value;"
docker exec -it mysql mysql -uroot -proot -e "USE superset; DELETE FROM cache_keys;"
docker compose restart superset
```

> 这个坑已解决，正常不会再现。**改 `SUPERSET_SECRET_KEY` 会重新触发**，所以 Key 定死后不要再改。

## 第 5 步：启动 Streamlit 智能问答（8501）

**再开一个 PowerShell 窗口 B**：

```powershell
cd D:\ydsh-datawarehouse
streamlit run streamlit_app.py
```

**预期输出**：
```
You can now view your Streamlit app in your browser.
Local URL: http://localhost:8501
Network URL: http://xxx:8501
```

**浏览器验证**：打开 **http://localhost:8501**

**依次输入这 4 个问题验证**：

| # | 问题 | 预期 |
|---|---|---|
| 1 | `各渠道GMV分布` | SQL 含 `group by channel`，返回 4 行 |
| 2 | `2024年4月广东省销售额是多少？` | SQL 含 `province='广东省'` + 日期范围 |
| 3 | `销量最高的前5个品类` | SQL 含 `order by ... desc limit 5`，5 行 |
| 4 | `复购率是多少` | 返回 1.0 |

**每个问题应展示**：生成的 SQL（代码块）+ 结果表格 + 图表（≥2 列时）+ 左侧历史记录。

**如果报错**：
- `TTransportException` / `Connection refused` → hive-server 没起或端口 10000 不通；
- `KeyError: DEEPSEEK_API_KEY` → `.env` 没配或不在当前目录；
- 模型生成 SQL 执行报错 → 换个问法再试。

## 常见问题速查表

| 现象 | 原因 | 解决 |
|---|---|---|
| `docker compose up` 报端口占用 | 3306/8088/10000 被占 | 改 `.env` 或 compose 端口映射 |
| hive-metastore 启动即退 | 缺 JDBC 驱动 | 确认 jar 在根目录、compose 挂载正确 |
| `ads_core_kpi` 查不到 | SQL 脚本没跑全 | 按部署手册第四节 11 个脚本顺序重跑 |
| Superset `Invalid decryption key` | `SUPERSET_SECRET_KEY` 变过 | 清 `dbs.encrypted_extra` + `key_value` + `cache_keys` |
| 大屏白屏 | api_server.py 没起 / CORS | 确认 5000 在跑，`pip install flask-cors` |
| Streamlit 连不上 Hive | hive-server 没起 | `docker ps` 确认 Up，端口 10000 |
| `KeyError: DEEPSEEK_API_KEY` | `.env` 缺失或位置错 | 确认 `D:\ydsh-datawarehouse\.env` 存在且含 Key |
